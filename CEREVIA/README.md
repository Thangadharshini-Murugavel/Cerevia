# 🧠 CEREVIA
### Less Short-Form. More Long-Form.

**CEREVIA** is a Java-based learning application designed to encourage meaningful long-form content consumption, focused thinking, and mindful digital habits.

Instead of endless short-form scrolling, CEREVIA promotes reading, knowledge exploration, cognitive exercises, and personal progress tracking.

## 🎯 Project Objectives

- Encourage meaningful long-form content consumption.
- Promote focused learning and attention.
- Strengthen memory, logical reasoning, and numerical skills.
- Track performance through progress statistics.
- Encourage mindful digital habits.

## ✨ Key Features

### 📚 1. Long-Form Content Hub

Explore educational content across five categories:

- Science
- Technology
- Psychology
- History
- General Knowledge

Each category provides internal educational articles and external learning resources.

### 🧠 2. Focus Training Centre

Practise cognitive skills through six interactive exercises:

1. Memory Challenge
2. Pattern Recognition
3. Attention Test
4. Logical Thinking
5. Quick Mathematics
6. Sequence Challenge

Each exercise provides questions, immediate feedback, and a final score.

### 📊 3. Progress Centre

Monitor learning and exercise performance through:

- Completed exercise tracking
- Total attempts
- Correct and incorrect answers
- Accuracy percentage
- Individual exercise performance
- Best scores

*Note: Progress is stored during the current application session and resets when the application closes.*

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project in a Java-supported IDE.
3. Ensure Java is installed and configured.
4. Locate `Main.java` inside the `main` package.
5. Run the `Main` class.
6. Explore the three modules through the main menu.

## 🌱 Project Vision

CEREVIA aims to promote a healthier relationship with digital content by encouraging people to spend more time learning, reading, thinking, and developing their attention.

It is built around one simple idea:

**Consume less. Learn more. Think deeper.**
