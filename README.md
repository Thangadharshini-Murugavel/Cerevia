# 🧠 CEREVIA

### Digital Consumption & Attention Enhancement System

**Less Short-Form. More Long-Form.**

CEREVIA is a Java-based console application designed to encourage long-form content consumption and improve attention through interactive focus-training exercises.

## ✨ Features

### 📚 1. Long-Form Content Hub

Explore 10 learning categories:

- Science
- Technology
- Psychology
- History
- General Knowledge
- Health & Biology
- Environment & Climate
- Business & Economics
- Space & Astronomy
- Arts & Literature

Each category provides:
- 5 built-in reading articles
- 5 external learning resources

**Total: 50 built-in articles and 50 external resources.**

### 🧠 2. Focus Training Centre

Six interactive games to practise attention, memory and logical thinking:

1. Memory Challenge
2. Pattern Recognition
3. Attention Test
4. Logical Thinking
5. Quick Mathematics
6. Sequence Challenge

Each game offers three difficulty levels:

- Basic – 3 questions
- Intermediate – 5 questions
- High Level – 7 questions

### 📊 3. Progress Centre

Track training performance through:

- Total attempts
- Correct and incorrect answers
- Best scores
- Exercise-wise progress
- Overall accuracy

**Note:** Progress is stored during the current application session and resets when the application is closed.

## ▶️ How to Run

1. Clone or download this repository.
2. Open Eclipse IDE.
3. Import the project as an existing Java project.
4. Ensure Java 15 or a compatible newer JDK is configured.
5. Keep the `articles` folder in the project root, alongside `src`.
6. Run `Main.java`.
7. Explore the Content Hub, Focus Training Centre and Progress Centre.

**Important:** Run the application with the project root as its working directory so the article files can be accessed correctly.

## 🎮 Navigation Guide

- `0` – Return to the previous menu.
- `00` – Exit the entire application.
- `E` – Exit the current focus exercise and return to the Focus Training Centre.

## 🎯 Project Objective

CEREVIA aims to promote meaningful digital consumption by encouraging users to spend more time learning through long-form content and practising focus through interactive exercises.
